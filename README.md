# LLM from Scratch

A small collection of notebooks and utilities for learning how large language models are built, with examples covering model architecture and attention mechanisms.

## Getting started

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
jupyter lab
```

Open the notebooks in JupyterLab and work through them in order, starting with `Building_LLM.ipynb`.
